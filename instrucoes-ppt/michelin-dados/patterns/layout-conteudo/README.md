# Conteúdo criado de um layout nativo

Usar para criar novos slides sem depender de um slide de exemplo. Campos: `title` e `body`. Usa o mestre `Slides Internos (Conteúdo)` e seu layout `Custom Layout 1 1 1 2 1 1 1 1 1 2`. Preenche o placeholder de título e adiciona texto na área central.

## Aprendizados

Criar pelo layout pode produzir um cabeçalho diferente do slide 2 original, que contém alterações locais. Esse comportamento é nativo do PowerPoint. O par mestre/layout evita a ambiguidade entre layouts homônimos de mestres diferentes. Referência: `michelin-example`, slide 3.
