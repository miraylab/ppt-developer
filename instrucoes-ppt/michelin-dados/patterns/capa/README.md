# Capa fotográfica

Usar para abrir uma apresentação de dados. Campos: `title` e `date` (texto de identificação, não precisa ser uma data). Duplica o slide original ID 256 e preenche os shapes 1227 e 2. Foto, slogan, logos e fonte do título vêm do template.

## Aprendizados

O subtítulo e a data têm o mesmo nome de shape, por isso o mapeamento usa IDs. Título deve ser curto para não invadir a foto. Referência: `michelin-example`, slide 1. Não substituir o slogan da marca por dados específicos da apresentação.
