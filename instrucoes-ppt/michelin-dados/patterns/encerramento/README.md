# Encerramento fotográfico

Usar para concluir a apresentação. Campos: `title` e `subtitle`. Duplica o slide ID 320 e preenche os placeholders de título e subtítulo, preservando foto, logos e formatação original.

## Aprendizados

O subtítulo original usa duas linhas. Manter identificação curta e revisar textos maiores para evitar cobrir a área principal da foto. Referência: `michelin-example`, slide 4.
